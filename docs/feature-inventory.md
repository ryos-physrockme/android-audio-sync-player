# 機能一覧 — Android Audio Sync Player

更新日: 2026-11-09  
対象実装: Androidアプリ `0.2.11-dev`（`app/build.gradle.kts`）。本書では **実装済み**、**部分対応・検証中**、**未実装**を区別する。

## アプリの目的

外部スピーカーなど、スマートフォンから制御できない機器が再生する音声をスマートフォンのマイクで聴き取り、端末内に保存した**同一録音**をイヤホンに自動同期して再生する。外部機器との通信やインターネット接続を要求しない。

## 実装済みの機能

| 分類 | 機能 | 操作・動作 | 制限 |
| --- | --- | --- | --- |
| 音源選択 | ローカル音声ファイルを選択 | Androidのシステムファイル選択画面から選択する | DRM付きの音源やストリーミングサービスは対象外 |
| 音源再生 | 再生・一時停止・再生位置の指定 | Media3 ExoPlayerで音声を再生する | 手動の再生操作ではマイク同期を停止する |
| 参照音源の解析 | 音響特徴量の事前計算 | 選択した音声を解析し、再生位置推定に使用する | 一定以上の録音長が必要、参照インデックスは約21分を上限とする |
| マイク入力 | 外部音声の取得 | 明示的に「マイクを開始」を押す | 画面が背後へ移ると録音を停止する |
| 再生位置の推定 | 同一録音への照合 | 約3秒の音声特徴列から候補時刻を求める | 別演奏、別編集、カラオケ伴奏との照合は未対応 |
| 誤認識の抑制 | 複数候補・時間的整合性の確認 | 最良候補と次候補との差、2回の連続した判定を確認する | 繰り返しフレーズや残響の強い場所では失敗し得る |
| 自動再生 | 初回に一度だけ自動シーク | 認識が確定するとローカル音源を対応する位置から再生する | その後は外部のシークや停止に自動追従しない |
| 再生開始の音量 | 約600 msのフェードイン | 自動開始と通常の手動開始時に音量を徐々に上げる | 正確な音響出力時刻の補償ではない |
| イヤホン時間補正 | 初回同期時のオフセット | −600〜＋600 ms、10 ms刻み。＋はローカル音源を先に進める | **次の初回同期**に反映し、再生中の即時変更は行わない |
| 判定条件の調整 | 一致度の閾値バー | 0.50〜0.95、0.01刻み。初期値0.72 | 別候補との差0.075以上と2回の連続判定は固定 |
| 再生中の手動補正 | −100 / −50 / ＋50 / ＋100 ms | 0.95倍または1.05倍で短時間再生し、時間差を少しずつ調整する | シークではないため補正完了は瞬間的ではない。未完了分は最大±500 ms |
| 設定保存 | 一致度閾値・初回同期オフセット | Androidのアプリ設定に保存する | 選択した音源の恒久的な履歴・プリセットは未実装 |
| 状態表示 | 再生時刻・入力レベル・照合状況・時刻差 | 推定時刻差の中央値とその変化を表示する | 推定時刻差はイヤホンから実際に聞こえる時刻差の測定値ではない |
| 画面回転 | 選択中の音源・再生をなるべく維持 | 通常の縦横回転でActivityの再作成を避ける | プロセス終了時の完全な再生復元は対象外 |
| ローカル処理 | オフラインで認識・再生 | マイク録音をネット送信しない | 選択した録音はユーザーが自分で用意する |

## 音声形式の対応状況

| 形式 | 再生 | 参照特徴量の解析 | 検証状況 |
| --- | --- | --- | --- |
| 16-bit PCM WAV（モノラル／ステレオ） | Media3 | 独自のRIFF/WAVE解析 | 実機で音源の読み込み・自動同期再生が動作したとの報告あり。同期誤差の測定は未実施 |
| MP3（固定／可変ビットレート） | Media3 | Android MediaExtractor / MediaCodec | 合成音源を使ったAndroidエミュレーターで再生準備・解析テスト成功。実機の外部音声同期は未検証 |
| M4A（AAC） | Media3 | Android MediaExtractor / MediaCodec | 合成音源を使ったAndroidエミュレーターで再生準備・解析テスト成功。実機の外部音声同期は未検証 |
| その他の拡張子・コーデック | 環境次第 | 環境次第 | 対応保証なし |

上表の「対応」はすべての端末、ファイル、編集版やエンコーダの組み合わせでの動作保証を意味しない。

## 未実装・構想段階

| 候補 | 現在の位置付け |
| --- | --- |
| アプリを閉じた後も「前回選んだ音源」を再選択できる機能 | 次の小規模改善候補 |
| イヤホン・出力機器ごとの時間補正プリセット | 異なる機器を日常的に切り替える場合に検討 |
| 曲別プリセットや名前付きプリセットの管理画面 | 現状では優先度低 |
| マイク入力からイヤホン遅延を自動較正 | 未実装 |
| 外部再生の停止・ジャンプへの自動追従 | 未実装（自動シークの振動を避けるため初回のみ） |
| 異なる録音同士の音楽同期（カラオケ伴奏と原曲など） | 別アルゴリズムを要する将来課題 |
| 生演奏のテンポ変化追跡 | 将来課題 |
| YouTubeなどの配信サービスとの連携 | 対象外 |
| バックグラウンドでのマイク常時利用 | 未実装 |
