# Android Audio Sync Player

スマートフォンのマイクで**外部機器から流れる音声**を聴き取り、端末内の**同じ録音**をイヤホンで自動同期再生するAndroidアプリ。外部機器との通信やインターネット接続を必要としない。

**現在の実装:** Android `0.3.1-dev`（2026-11-09時点）。開発・検証中のアプリであり、同期精度やイヤホン遅延の自動補正を保証しない。

## 主な機能

- Androidのファイル選択画面からローカル音声を選択して再生する。
- WAV（16-bit PCM）の音声特徴量を端末内で作り、マイクで拾った**同一録音**の位置を認識する。
- MP3（固定／可変ビットレート）とAAC入りM4Aの再生準備・特徴量解析も実装し、合成音源を使ったAndroidエミュレーターのテストに成功している（実機での音響同期は未検証）。
- 外部音声の位置を認識したら、**初回に1回だけ**ローカル音源を同期位置へ移動し、約600 msでフェードインする。再生中に自動シークは繰り返さない。
- 再生中は `−100 / −50 / ＋50 / ＋100 ms` のボタンで、再生速度を一時変更して時間差を徐々に調整する。
- 同期オフセット（次の初回自動同期時、−600〜＋600 ms）と、一致度閾値（0.50〜0.95）を設定・保存する。
- 同期判定、時刻差の推定値、音源の形式や解析エラーを表示する。

## 画面構成

0.3.0-devから、暗い環境でも使いやすい簡潔な画面に整理した。

- **上:** 選択中の音源名と「変更」、解析状態。
- **中央:** 大きな「同期を開始」ボタンと、常時確認できる認識・照合状態（候補時刻・一致度）。その下の「同期オフセット」スライダーは次回の自動同期時の再生位置にだけ適用する。認識中・同期再生中は「認識を停止」に変化する（停止してもローカル再生は継続）。
- **下:** 小さいシークバー、`−100 / −50 / +50 / +100` の補正ボタン、**要求した手動補正の符号付き合計**、補助的な再生・一時停止ボタン。
- **設定・診断:** 一致度閾値、音声形式、マイク状態、照合詳細、時刻差、再生状態を項目別に整理して、必要なときだけ展開する。

「補正 +150 ms」は利用者がボタンで**要求した補正量の正味の合計**であり、実際のイヤホン出力で達成された補正量や未完了量の推定値ではない。再生速度の補正が進んでもこの値は自動的には変化しない。音源変更や新しいマイク照合セッションではゼロに戻る。

アプリのアイコンは、ヘッドホンと音声波形を組み合わせたAndroidアダプティブアイコンで、[SVG版](docs/design/app-icon.svg)も同梱する。

## 使い方

1. スマートフォンと別の再生機器に**同一の録音**を用意する。
2. アプリでローカル音源を選択し、「解析完了」を確認する。
3. イヤホンを接続し、「同期を開始」を押す。
4. 外部機器で録音を再生する。認識条件を満たすとアプリ側も自動再生を開始する。
5. 必要に応じて、再生中の `±50 ms`／`±100 ms` ボタンで補正する。

**注意:** 「再生」ボタンは通常の手動再生用で、押すとマイクによる同期を停止する。外部機器で一時停止・シークした場合に再同期するには、マイクを停止して開始し直す。アプリがバックグラウンドへ移るとマイク入力は停止する。

## 開発・ビルド

- Android Studio、Java 17、Android SDK API 36、Gradle Wrapper 8.13。
- Androidの最小APIレベルは26。
- Windows: `gradlew.bat :app:testDebugUnitTest :app:assembleDebug`
- Linux / macOS: `./gradlew :app:testDebugUnitTest :app:assembleDebug`
- GitHub Actionsは単体テストとデバッグAPKのビルドを行う。MP3・M4Aの一部はAndroidエミュレーター上でもテストする。
- [GitHub Actions](https://github.com/ryos-physrockme/android-audio-sync-player/actions) の成功したAndroid build実行の **Artifacts → android-debug-apk** から実験用APKを取得できる。成果物の保存期間には限りがある。
- GitHub Actionsのデバッグ用署名がビルド間で変わる場合、以前のAPKに上書きインストールできない。アプリ内設定の消去に注意する。

## 対応状況と今後の検討

実機では少なくともPCM WAVの読み込み・特徴量解析・同一録音からの自動再生が動作したとの報告がある。ただし、**音響的な同期誤差の実測値はまだない**。MP3・M4Aはローカルデコードのエミュレーターテストまで完了しており、外部音声との実機同期が今後の検証対象となる。

プリセットの本格的な管理画面は未実装。現状、閾値と初回オフセットは保存される。操作負担を減らすためには、曲別プリセットよりも**前回の音源を再選択しやすくする機能**を先に検討する。

## プライバシー・権利

マイクの音声は端末内で処理し、録音を保存・アップロードしない。著作権のある楽曲をリポジトリに同梱しない。ユーザーが使用する音声ファイルの権利は各自で確認する。

このリポジトリはライセンスをまだ選択していない。依存ライブラリと配布条件を確認してから一般公開・配布方針を決定する。
